# Muhammed Fazal — Portfolio

Personal portfolio website showcasing my work as a Backend Engineer specializing in Go.

🔗 **Live**: [muhammedfazall.github.io/Portfolio](https://muhammedfazall.github.io/Portfolio)

## Tech Stack
- Pure HTML, CSS, JavaScript
- Google Fonts (Syne + Space Mono)
- Font Awesome Icons
- Web3Forms (contact form)

## Sections
- **Hero** — Animated intro with typewriter effect and Go code window
- **About** — Background and experience overview
- **Skills** — 6-category technical skill grid
- **Experience** — Timeline showing work history
- **Projects** — Featured projects (MoneyMate, Sendr)
- **Contact** — Working contact form + social links

## Deploy
Push to GitHub and enable GitHub Pages from Settings → Pages → Source: main branch.
